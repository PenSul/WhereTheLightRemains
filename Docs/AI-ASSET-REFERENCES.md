Provider reference: **OpenAI (2026), project-specific AI-assisted visual development** — [OpenAI](https://openai.com/). Specific model identifiers were not retained for the earlier reference assets, so no model/version is claimed. The selection date is not presented as an exact generation timestamp. Human direction, selection and in-game acceptance remain separate from the assistance used to create an asset.

Font, paper and model sources retain their own creator/license entries and original notices. No existing third-party creator attribution is replaced by an AI label. New generated or assisted assets need corresponding entries when they are accepted/imported, including provider/model/date/prompt references where recorded and actual modifications. Private candidates are not represented as finished game assets.
